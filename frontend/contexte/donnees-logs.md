# Données des logs

- Niveaux de sévérité : Critique, Normal, Info ou Warning (nom exact à confirmer dans `client/src/components/types.ts`).
- Vues de logs : `NetworkLogs.tsx`, `LogsManagement.tsx`, `ThreatIntel.tsx` (+ autres repérées à l'audit).
- Champs affichés dans le détail déroulé : tous ceux de l'objet log disponible (à lister après lecture de `types.ts`).
